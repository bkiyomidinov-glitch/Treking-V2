# ПРОМТРЕК — Система учета производства, остатков в цехах и трекинга товаров

Современная система складского и производственного учета, контроля партий и трекинга перемещения готовой продукции и полуфабрикатов по цехам и распределительным центрам.

## Основные возможности

1. **Каталог товаров и номенклатура**:
   - Добавление и редактирование товаров (наименование, артикул SKU, штрихкод EAN-13 префикс 485, категория, единицы измерения, цены и себестоимость в сомони).
   - Генерация штрихкодов и артикулов в 1 клик.
   - **Date Picker** для даты производства и гарантийных сроков.
   - **Switch-переключатели** для статусов (Сертификат ГОСТ/ТУ, Хрупкий груз, Температурный режим, Активность для продажи).
   - Добавление новых вариантов атрибутов (цвет, сезон, размер) **на лету прямо в форме товара** (+ Вариант).

2. **Управление цехами и складами**:
   - Полный CRUD: создание новых цехов, складов, шоурумов и транзитных хабов в городах Таджикистана (Душанбе, Худжанд, Бохтар, Куляб, Хорог и др.).
   - Редактирование и удаление цехов в один клик.
   - Точный количественный учет: сколько единиц каждого изделия находится в конкретном цехе.
   - Сводная матрица остатков (Pivot-таблица «Товар × Цех / Склад»).
   - Перемещение партий с валидацией доступного остатка.

3. **Сквозной трекинг и цифровой паспорт партии**:
   - Пошаговый визуальный прогресс технологического цикла (Заготовка → Пошив/Сборка → Контроль ОТК → Склад → Доставка).
   - Векторный штрихкод SVG для моментального сканирования и печати.
   - Неизменяемый журнал перемещений (WORM audit trail) с SHA-256 хешированием каждого события.

4. **Конструктор и управление атрибутами**:
   - Создание, редактирование и удаление характеристик любого типа:
     - `Выбор из списка (Select)` с удалением и добавлением вариантов по отдельности
     - `Календарная дата (Date Picker)`
     - `Переключатель Да/Нет (Switch)`
     - `Текстовые поля (Text)`
     - `Числовые значения с единицами измерения (Number)`

5. **Справочники предприятия (MDM) и локализация**:
   - Полный CRUD для всех справочников: **Цеха и склады**, **Персонал**, **Автопарк** и **Маршруты** (добавление, редактирование, удаление в один клик).
   - Полная привязка к инфраструктуре Таджикистана: города (Душанбе, Худжанд, Бохтар, Куляб и др.), сомони (TJS), автономера Таджикистана и маршруты.

## Запуск проекта

### 1. Установка зависимостей:
```bash
pip install -r requirements.txt
```

### 2. Запуск локального сервера:
```bash
uvicorn app:app --reload --host 127.0.0.1 --port 8000
```

### 3. Открытие в браузере:
Перейдите по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000)
