# ПРОМТРЕК (Treking-V2) — Корпоративная система учета производства, логистики и трекинга товаров

Современная корпоративная система складского и производственного учета, контроля партий, ролевого доступа (RBAC), неизменяемого блокчейн-аудита (WORM SHA-256 Ledger) и трекинга перемещения продукции по цехам и распределительным центрам.

---

## Основные возможности

### 1. 🛡️ Корпоративная безопасность, аутентификация (AuthN) и RBAC
- **Надежное хеширование паролей**: библиотека `bcrypt` со стандартным фактором 12 раундов соли.
- **JWT-токены**: эндпоинт `/api/auth/token` (поддержка JSON и OAuth2 Password Grant Form) с проверкой активности пользователя (`is_active`).
- **Универсальная ролевая модель (`RoleChecker`)**:
  - `admin` — полный CRUD, управление пользователями, справочниками (MDM), удаление товаров и системный сброс.
  - `manager` — создание и редактирование номенклатуры, оформление отгрузок и перемещений, просмотр аудита.
  - `storekeeper` — приемка на склад, межцеховые перемещения, фиксация этапов.
  - `qc` — инспекция контроля качества (ОТК), изменение статусов ОТК (`/api/products/{id}/qc`) с фиксацией дефектов и заметок.
  - `worker` — просмотр задач, сканирование штрихкодов изделий и просмотр паспортов партий.
- **Стандартизированные HTTP-статусы**: 401 Unauthorized, 403 Forbidden с информативными сообщениями.

#### 👥 Учетные записи по умолчанию для быстрого тестирования:
| Логин | Пароль | Роль | Описание |
|---|---|---|---|
| `admin` | `admin123` | **Администратор** | Полный доступ ко всем функциям и пользователям |
| `manager` | `manager123` | **Менеджер** | Создание товаров, перемещения, журнал аудита |
| `storekeeper` | `store123` | **Завскладом** | Приемка и перемещения остатков |
| `qc` | `qc123` | **Инспектор ОТК** | Контроль качества и отбраковка |
| `worker` | `worker123` | **Мастер цеха** | Только просмотр задач и сканирование |

### 2. ⛓️ Неизменяемый журнал аудита (WORM Audit Trail & SHA-256 Ledger)
- Таблица `audit_logs` фиксирует каждую операцию (создание, изменение, удаление, перемещение, логины).
- **Криптографическая цепочка целостности**: каждая запись запечатывается хешем `current_hash = SHA-256(prev_hash + user_id + action + entity + payload + timestamp)`.
- **Эндпоинт верификации `/api/audit-logs/verify`**: проводит сквозную математическую валидацию реестра от генезис-блока до вершины и выявляет любые попытки подделки.
- **Аппаратная WORM-защита (Write Once, Read Many)**: триггеры СУБД блокируют любые `UPDATE` или `DELETE` в таблице аудита.
- **Высокопроизводительные индексы** для нагрузок >500k операций в месяц: `idx_audit_logs_user_date(created_at, user_id)`, `idx_users_username`, `idx_users_role`.

### 3. 🐘 Поддержка Big Data и переход на PostgreSQL
- **Абстрактный слой БД (`database.py`)**: прозрачная совместимость как с локальным SQLite, так и с высоконагруженным PostgreSQL через единый пул соединений.
- **Автоматическая адаптация запросов**: трансляция плейсхолдеров `?` в `%s` и `INSERT OR IGNORE` в `ON CONFLICT DO NOTHING`.
- **Готовая схема PostgreSQL (`schema_postgres.sql`)**: типы `NUMERIC`, `JSONB`, `TIMESTAMP WITH TIME ZONE`, составные индексы и WORM-триггеры.
- **Скрипт миграции (`migrate_to_postgres.py`)**: переносит все справочники, номенклатуру, остатки и криптографический аудит в PostgreSQL в один клик.

```bash
# Перенос данных в PostgreSQL:
python migrate_to_postgres.py --postgres-url "postgresql://postgres:password@localhost:5432/treking_db"

# Запуск приложения на PostgreSQL:
$env:DATABASE_URL="postgresql://postgres:password@localhost:5432/treking_db"
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

---

### 4. 📦 Номенклатура, трекинг и единицы измерения
- **Каталог товаров**: артикулы SKU, штрихкоды EAN-13 (префикс Таджикистана 485), категории, цены и себестоимость в сомони (TJS).
- **Динамические единицы измерения**: штуки, метры, рулоны, бобины, комплекты — пользователь может добавлять свои собственные единицы или удалять ненужные.
- **Динамические флаги изделий**: переключатели (Сертификат, Хрупкий груз, Температурный режим, Активен) полностью настраиваемы и не захардкожены.
- **Сквозной цифровой паспорт**: технологический цикл (Заготовка → Пошив/Сборка → Контроль ОТК → Склад → Доставка) с векторным штрихкодом SVG.

## Запуск проекта

### 1. Установка зависимостей:
```bash
pip install -r requirements.txt
```

### 2. Запуск локального сервера:
```bash
python -m uvicorn app:app --reload --host 127.0.0.1 --port 8000
```

### 3. Запуск комплексных тестов безопасности и аудита:
```bash
python test_security.py
```

### 4. Открытие в браузере:
Перейдите по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000)
(Для быстрого входа используйте кнопки быстрого входа под любой ролью: Администратор, Менеджер, Завскладом, ОТК или Мастер цеха).
